Rule 1 — Host owns Systems. Every class in 2_Systems/ is either Pure C# or a NetworkBehaviour that only runs its logic when IsServer is true. Rule 2 — Clients react, they don't decide. Any script under 3_Entities/ or 5_UI/ may read NetworkVariables and subscribe to EventChannelSO events. It may never call a method on a 2_Systems/ class directly. Rule 3 — Input goes up, state comes down. Client input travels to the Host via ServerRpc. Resulting state changes travel back down via NetworkVariable sync or ClientRpc. If you're about to write code that reads local input and directly changes Sanity, Station, or Monster state without going through the Host — stop. Route it through a ServerRpc instead.
